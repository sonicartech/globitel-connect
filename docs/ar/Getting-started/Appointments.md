# سجل المواعيد (مواعيدي)

---
تُوفر ميزة سجل المواعيد (الحجوزات) نظرة شاملة على المواعيد القادمة والمجدولة مع العملاء.

كيف يمكنني الوصول إلى قائمة المواعيد؟

في صفحة "لوحة القيادة"، يمكنك عرض تفاصيل المواعيد من خلال علامة التبويب الخاصة ب "مواعيدي". بحيث تتوفر المعلومات التالية:

| الاسم | الوصف |
| ------------ | --------- |
| وقت الموعد | هذا يعرض تاريخ ووقت الموعد الذي تم حجزه من قبل العميل. |
| حالة إكمال المكالمة | هذا يعرض حالة المكالمة إذا كانت قادمة أو تم إكمالها أو أعيدت جدولتها أو تم إلغائها. |
