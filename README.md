# Globitel Connect User Manual

The official user manual for **Globitel Connect**, in English and Arabic, with a built-in AI assistant.

[**🌐 Live site**](https://globitel-connect.sonicar.tech) ·

[🇸🇦 العربية](https://globitel-connect.sonicar.tech/ar/) ·

## ✨ Features

- **English and Arabic (RTL).** Two complete editions, with a language switcher on every page.
- **AI assistant.** A chat widget answers questions in either language using only the manual, and links to the pages it used. It runs on a Cloudflare Worker with Workers AI ([`chatbot-worker/`](chatbot-worker/)).
- **PDF manuals.** A printable PDF for each language, with a custom cover page.
- **Search.** Full-text search with suggestions, highlighting and shareable result links.
- **Light and dark mode.** Uses a Globitel color scheme and follows your system setting.
- **Page feedback and analytics.** Readers can rate each page ("Helpful?"), and Google Analytics is set up.
- **Image zoom.** Click any screenshot to open it in a lightbox.


## 🚀 Getting started

### Prerequisites

- Python 3.9+
- Node.js 18+ (only needed for the AI assistant)

### Install

```sh
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### Preview locally

```sh
mkdocs serve -f mkdocs.yml         # English → http://127.0.0.1:8000
mkdocs serve -f mkdocs.ar.yml      # Arabic
```

### Build

```sh
./build.sh
```

This builds the English site into `en/` and the Arabic site into `ar/`, then regenerates the assistant's knowledge base (`chatbot-worker/src/knowledge.json`) from both search indexes.

## 🤖 AI assistant

The chat widget calls the Worker at `extra.chatbot.endpoint` in `mkdocs.yml`. You can override this URL with the `GC_CHATBOT_ENDPOINT` environment variable. If the endpoint is empty, the widget is hidden.

```sh
cd chatbot-worker
npm install
npm run dev                        # local Worker at http://localhost:8787
npm run deploy                     # publish to Cloudflare
```

To test the site with a local Worker:

```sh
GC_CHATBOT_ENDPOINT=http://localhost:8787 mkdocs serve -f mkdocs.yml
```

See [`chatbot-worker/README.md`](chatbot-worker/README.md) for the model, allowed origins and rate-limit settings.

## 🌍 Deployment

The built output is plain static HTML, so it can be hosted on **Netlify**, **Cloudflare Pages**, cPanel or any static server. Upload the repository root (including `en/`, `ar/`, `index.html`, `404.html` and `_redirects`).

After editing the docs:

1. Run `./build.sh`.
2. Run `cd chatbot-worker && npm run deploy` so the assistant uses the updated content.
3. Commit and deploy the static files.

## ✍️ Contributing to the docs

- Pages are Markdown files in `docs/en/` and `docs/ar/`. Each language has its own navigation (`nav`) in its config file.
- When you add a page, add it to **both** configs (`mkdocs.yml` and `mkdocs.ar.yml`) unless the page is English-only.
- Put screenshots in `docs/<lang>/assets/<Section>/`.
- The PDF is generated by `mkdocs-print-site-plugin`. Its cover template is in `docs/en/assets/templates/`.
